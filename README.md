# Bada Hair — Premium Redesign Concept

Independent front-end redesign concept for Bada Hair Korean Hair Salon, Singapore.

## Files
- `index.html`
- `style.css`
- `script.js`

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## GitHub Pages
1. Create a public repository.
2. Upload these files to the repository root.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Notes
- This is an unofficial concept and includes `noindex, nofollow`.
- Images/video are loaded from remote stock-media URLs for demo purposes.
- Replace stock media with licensed/original Bada Hair assets before a production launch.
- Booking form prepares a WhatsApp message; it does not store data.
